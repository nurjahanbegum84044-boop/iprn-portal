API Documentation

POST https://api.2oo9.cloud/MXS47FLFX0U/tness/@public/api/getnum
Allocate one number from a range — same as the dialer Get Number.
{ "rid": "26134" // range digits (no XXX), OR a search-picker range_id }
{ "meta": { "code": 200, "status": "ok" }, "data": { "full_number": "+447404333228", "national_number": "7404333228", "no_plus_number": "447404333228", "country": "United Kingdom", "operator": "EE" }, "message": "number allocated", "rid": "…" }
mauthapi: <your_api_key>

rid = the range number WITHOUT the trailing XXX (e.g. 26134), or a search-mode range_id.

Every response uses the standard envelope { meta:{code,status}, data, message, rid } — same as the dashboard, just plain JSON.

Out of stock → meta.code 2946 / status "not_found", data null.

GET https://api.2oo9.cloud/MXS47FLFX0U/tness/@public/api/liveaccess
Recently-active services + the ranges each one hit (the getnum Access cache).
{ "meta": { "code": 200, "status": "ok" }, "data": { "cached": true, "services": [ { "sid": "Telegram", "last_at": 1779460000000, "ranges": ["22501XXX", "8801XXX"] } ] }, "message": "ok", "rid": "…" }

Same response for every caller; cached 60s.

Console-hidden services are excluded.

GET https://api.2oo9.cloud/MXS47FLFX0U/tness/@public/api/success-otp
Your own last 50 successful OTPs.
{ "meta": { "code": 200, "status": "ok" }, "data": { "cached": false, "otps": [ { "otp_id": "4474043332281779460000000", "number": "447404333228", "message": "Your code is 123456", "time": 1779460000000 } ] }, "message": "ok", "rid": "…" }

Only numbers allocated to you.

otp_id = number + time(ms).

time = unix-ms when the OTP hit.

Cached 5s per user.

GET https://api.2oo9.cloud/MXS47FLFX0U/tness/@public/api/console
Global live feed of recent hits (last 15 minutes).
{ "meta": { "code": 200, "status": "ok" }, "data": { "cached": false, "hits": [ { "range": "22501XXX", "sid": "WhatsApp", "message": "Your code 998877", "time": 1779460000000 } ] }, "message": "ok", "rid": "…" }

Global — all traffic.

Console hide rules applied (hidden uid / sid / keyword rows dropped).

Cached 5s.
